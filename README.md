# Иврит с нуля

Тренажёр иврита для iOS: ежедневная сессия на 5–10 минут, от незнакомого алфавита до
уверенного чтения и базового словаря. Интерфейс на русском, учебный материал — на иврите
с огласовками (никуд).

Expo SDK 54 · React Native 0.81 · TypeScript (strict) · expo-router. Прогресс хранится
только на устройстве, аккаунта и бэкенда нет.

## Как запустить

```bash
npm install
npx expo start
```

Дальше:

- **iOS на устройстве** — отсканируйте QR-код камерой и откройте в Expo Go.
- **iOS-симулятор** — `npx expo start --ios` (нужен macOS с Xcode).
- **Браузер** (быстрая проверка вёрстки) — `npx expo start --web --port 43127`.

Полезные команды:

```bash
npm run typecheck   # tsc --noEmit, strict
npm test            # jest: планировщик SM-2 и правила очереди
npm run lint        # expo lint
```

Сбросить прогресс можно внутри приложения: «Сегодня» → шестерёнка → «Сбросить прогресс».

## Что внутри

### Экраны

| Экран        | Что делает |
| ------------ | ---------- |
| **Сегодня**  | Кнопка «Начать», очередь из 15 карточек, счётчик серии дней, быстрые разминки |
| **Алфавит**  | 22 буквы с названиями, звуками и примерами; конечные формы; таблица огласовок; режимы «узнай букву» и «напиши букву» |
| **Слова**    | 5 колод, карточка со словом: никуд, написание без огласовок, транскрипция (кириллица и латиница), перевод, озвучка |
| **Чтение**   | Короткие фразы с никудом и переключатель на текст без огласовок; задание — прочитать вслух и выбрать перевод |
| **Прогресс** | Выученные буквы, слова и фразы, точность, что повторить сегодня, активность за 7 дней, слабые места |

Онбординг из трёх шагов (уровень → цель → время в день) открывается один раз, до первой
сессии, и сохраняет выбор в настройки.

### Алгоритм повторений

`lib/srs.ts` — SM-2: ease стартует с 2.5 и не опускается ниже 1.3, интервалы 1 → 6 →
`предыдущий × ease`. Оценки: «С трудом» / «Нормально» / «Легко» для верного ответа.

Правила сессии (`lib/session.ts`):

- очередь не длиннее 15 карточек;
- не больше 5 новых слов за сессию (плюс до 4 новых букв и 2 новых фраз), поэтому самая
  первая сессия короче — 9 карточек, пока не накопились повторения;
- ошибка сбрасывает интервал в ноль и отправляет карточку в конец текущей очереди;
- фразы для чтения открываются после 10 введённых букв;
- если уровень «умею буквы», новые буквы не вводятся;
- когда на сегодня всё повторено, экран «Сегодня» показывает это состояние и предлагает
  необязательное досрочное повторение.

### Данные

Весь учебный материал лежит в `data/hebrew.json` и проверен вручную:

- 22 буквы + 5 конечных форм (ך ם ן ף ץ), название на иврите и по-русски, звук, пример слова;
- 9 огласовок;
- 40 слов в 5 колодах: частые слова (12), числа (8), семья (7), еда (7), глаголы в
  настоящем времени (6). У каждого слова есть `nikud`, `plain`, транскрипция и перевод;
- 10 фраз для чтения с вариантами перевода.

Приложение никогда не генерирует никуд само. Новые слова добавляются только в этот файл,
после сверки со словарём.

### Хранение

`lib/storage.ts` — один JSON-документ в AsyncStorage под ключом `hebrew-coach/progress/v1`:
состояния карточек SM-2, журнал сессий, серия дней и настройки. В `migrate()` есть точка
для будущих версий схемы.

### Оформление

- Иврит рендерится компонентом `HebrewText`: `writingDirection: 'rtl'`, выравнивание по
  правому краю, кегль 32 / 56 / 96 — меньше 32 не бывает.
- Тёмная и светлая темы в `constants/theme.ts`, переключатель в настройках (системная /
  светлая / тёмная).
- Пустые состояния на всех экранах, где данных может не быть.

### Озвучка

Сейчас это `expo-speech` с языком `he-IL` (`lib/speech.ts`). На iOS качество зависит от
установленного голоса: если иврит не скачан в «Настройки → Универсальный доступ → Устный
контент → Голоса», озвучка может молчать.

## Что осталось сделать

**Аудио носителя языка.** Заменить `expo-speech` на записанные файлы: по одному на букву,
слово и фразу. Нужны сам набор записей, `expo-av` (или `expo-audio`) вместо
`expo-speech`, поле с путём к файлу в `data/hebrew.json` и фолбэк на синтез, пока записи
нет.

**Колоды до полного размера.** В JSON уже указан `plannedSize` для каждой колоды — сейчас
загружено 40 слов из ~200. Нужно добить «100 самых частых слов» до сотни, числа до 20,
расширить семью, еду и глаголы; у каждого слова выверить огласовки и род.

**Распознавание рукописного ввода.** Режим «напиши букву» работает как припоминание с
самопроверкой: показываем название и звук, пользователь пишет на бумаге, затем сверяется с
начертанием. Полноценная версия требует canvas для рисования пальцем и сверки траектории.

**Произношение вслух.** Задание «прочитать вслух» пока отмечается самим пользователем.
Автоматическая проверка потребует распознавания речи на иврите.

**Публикация в App Store.** Не сделано: иконка и splash остались шаблонными,
`bundleIdentifier` — заглушка `com.example.hebrewcoach`. Нужны реальный bundle ID, иконки,
скриншоты, политика конфиденциальности (пригодится то, что данные не покидают устройство),
сборка через EAS (`eas build -p ios`) и загрузка в TestFlight.

**Остальное.** Напоминания о тренировке (`expo-notifications`, время берётся из онбординга),
экспорт и импорт прогресса, тесты на UI-компоненты (сейчас покрыты только `lib/srs.ts` и
`lib/session.ts`).
