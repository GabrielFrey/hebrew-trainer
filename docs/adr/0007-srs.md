# ADR 0007 — SRS intervals

**Status:** accepted  
**Date:** 2026-10-22

## Context

The product wants a simple, explainable schedule, not FSRS.

## Decision

Fixed steps: **1, 3, 7, 14, 30** days (configurable in `apps/api/biti/gamification.py`). Correct advances one step; incorrect resets to 1 day. Due dates are calendar dates in the learner timezone. SRS never spends hearts. Sessions mix he→ui, ui→he, audio (if available), and conjugation.

## Consequences

Not comparable to Anki/FSRS memory models. Timezone/DST tests must use explicit IANA zones.
