# ADR 0002 — Authentication

**Status:** accepted  
**Date:** 2026-10-22

## Context

Learners need persistent progress across devices. Editors need audited roles. The environment may not have Keycloak running.

## Decision

- Production path: OIDC Authorization Code + PKCE against Keycloak (Compose). Short-lived access JWT, rotating refresh.
- Web: HttpOnly cookies + CSRF double-submit. Mobile: bearer access token; refresh in SecureStore.
- Roles `learner`, `editor`, `content_admin`, `system_admin` are enforced in the API.
- `BITI_DEMO_MODE` issues a local signed JWT for development only. If `BITI_ENV=production` and demo mode is on, the process refuses to start.
- Demo mode is labeled in API responses (`auth.mode = demo`).

## Consequences

This workspace can exercise the learning loop without Keycloak. A live OIDC round-trip is unverified until Compose Keycloak is running.
